# Automated Metadata Generation Pipeline

The Next.js `generateMetadata` function combined with `src/lib/seo.ts` forms an automated pipeline that ensures perfect metadata formatting without manual entry.

## Pipeline Architecture

1. **Route Level (`page.tsx`):** Retrieves data from JSON source based on the URL slug.
2. **Metadata Wrapper (`seo.ts`):** Takes raw data and formats it into Next.js Metadata objects.

### `src/lib/seo.ts` (Already Implemented Conceptually)

```typescript
// Core logic inside constructMetadata()

export function constructMetadata({
  title,
  description,
  path,
  keywords = [],
  image = "/og-image.jpg"
}: MetadataProps): Metadata {
  const baseUrl = getBaseUrl();
  const url = `${baseUrl}${path}`;

  // Enforce Character Limits (Optional programmatic safety net)
  const safeTitle = title.length > 60 ? title.substring(0, 57) + "..." : title;
  const safeDesc = description.length > 155 ? description.substring(0, 152) + "..." : description;

  return {
    metadataBase: new URL(baseUrl),
    title: safeTitle,
    description: safeDesc,
    alternates: {
      canonical: url, // Absolutely critical for preventing duplicate content
    },
    // ... OG and Twitter graph logic
  }
}
```

By passing only the unique `title`, `description`, and `path`, the pipeline automatically ensures the canonical URL is correct across all environments (Local, Vercel Preview, Production) and that OpenGraph tags are consistently injected.
