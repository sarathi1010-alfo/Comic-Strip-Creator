# Content Pruning Decision Framework

Programmatic SEO can lead to index bloat. If a page has no value, it drains crawl budget and dilutes domain authority.

## The Rule of 6 Months
Do not prune programmatic pages less than 6 months old unless they are causing technical errors.

## Evaluation Criteria (Per Page)
Evaluate pages older than 6 months:
1. **Impressions:** < 100 / month
2. **Clicks:** 0 / month
3. **Backlinks:** 0 external links

## Decision Matrix

| Scenario | Decision | Action |
| :--- | :--- | :--- |
| **0 Clicks, 0 Impressions, 0 Links** | **Prune** | Remove from JSON data source. Serve 404 (or 410). Remove internal links. |
| **0 Clicks, High Impressions, Position > 30** | **Optimize** | Keep page. Add internal links. Expand content. Add to "Latent Rankers" list. |
| **High Clicks, Low Engagement Time (<10s)** | **Revise Intent** | Keep page. Redesign UI. The searcher is landing but leaving immediately. |
| **Duplicate/Cannibalizing another page** | **Consolidate** | Setup 301 redirect to the stronger page. Merge content if relevant. |

## Pruning SOP
1. Identify target URLs using GSC + GA4 data.
2. Verify zero external backlinks (using Ahrefs/Semrush). If it has links, **DO NOT 404**. 301 redirect it to a related hub.
3. Remove URL from the Next.js `data/` source JSON.
4. Add 301 redirect in `next.config.ts` if consolidating.
5. Deploy.
6. Verify URL is removed from `sitemap.xml`.
