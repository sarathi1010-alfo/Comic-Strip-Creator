# Keyword Expansion Loop

Use this exact prompt weekly with ChatGPT/Claude to process GSC query data and generate new programmatic pages.

---

**Prompt:**

```text
I am running a weekly keyword expansion loop for my Next.js programmatic SEO site (a client-side Comic Strip Creator).

Here is my GSC query data showing terms where I currently rank between position 15-50:
[PASTE GSC EXPORT HERE]

My current site architecture has these clusters:
- /use-cases/ (Target audiences and specific usage scenarios)
- /templates/ (Specific comic layouts)
- /vs/ (Comparisons)
- /blog/ (Informational)

Analyze the queries and provide:
1. 10 NEW programmatic page ideas that directly address the search intent of these latent queries.
2. Assign each idea to one of my existing clusters.
3. Provide the exact target URL slug (e.g., `comic-strips-for-history-class`).
4. Suggest the H1 and Title Tag.
5. Identify any queries that indicate a feature request for the core `/editor` tool itself.

Output as a Markdown table.
```
