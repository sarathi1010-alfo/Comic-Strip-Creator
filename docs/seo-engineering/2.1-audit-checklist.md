# Indexing Audit Checklist

Run this checklist after every batch deployment of programmatic SEO pages to ensure maximum indexing probability and prevent indexing failure modes.

| Check | How to Test | Pass Criteria | What to Fix If Failing |
| :--- | :--- | :--- | :--- |
| **Noindex Tag Check** | View Source (`Ctrl+U`) -> `Ctrl+F` "noindex" | `robots="noindex"` must NOT be present on production pages. | Check `src/app/layout.tsx` metadata. Ensure `VERCEL_ENV` logic isn't applying noindex to production. |
| **JS Rendering Blocking** | Disable JS in browser / use Google Mobile-Friendly Test. | Core content (H1, text, images) must be visible without JS. | Move data fetching to Server Components (SSR/SSG). Do not use `useEffect` for critical text rendering. |
| **Canonical Tags** | View Source -> `Ctrl+F` "canonical" | Tag exists, matches the EXACT current URL (no query strings), and is absolute (https://). | Fix `src/lib/seo.ts` `constructMetadata` canonical logic. |
| **Internal Link Graph** | Run Screaming Frog or Sitebulb. | Page must have > 0 inlinks. Must be reachable within 3 clicks from homepage. | Add internal links in the cluster Hub page or use the automated "Related Pages" widget. |
| **Sitemap Presence** | Check `example.com/sitemap.xml`. | The new URL must be present in the sitemap. | Fix `src/app/sitemap.ts` to ensure the new JSON data source is included. |
| **Duplicate Content** | Search GSC for the URL. | Must not be flagged as "Duplicate, Google chose different canonical". | Ensure the page content is sufficiently unique from templates. Adjust URL structure to avoid parameters. |
| **Server Response (5xx)** | Load page, check Network tab. | Status 200 OK. No 500 errors. | Check Vercel function logs for unhandled exceptions in `page.tsx` or data fetching APIs. |
