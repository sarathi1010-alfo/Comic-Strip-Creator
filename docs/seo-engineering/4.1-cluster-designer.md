# Cluster Architecture Designer

To build topical authority, pages cannot exist in isolation. They must be grouped into Semantic Clusters using a Hub-and-Spoke model.

## Example Cluster: Education (`/use-cases/education`)

**Hub Page:** `/use-cases/education` (H1: "The Complete Guide to Using Comic Strips in the Classroom")

**Spoke Pages (Programmatic Targets):**
- `/use-cases/teachers` (For educators)
- `/use-cases/students` (For learners)
- `/use-cases/history-class` (Specific subject)
- `/use-cases/language-learning` (Specific subject)

**Supporting Informational Content (Blog):**
- `/blog/how-to-grade-a-comic-strip-assignment`
- `/blog/benefits-of-visual-learning-with-comics`

## The Linking Graph
1. The **Hub** links to ALL Spoke pages and Blog posts within the cluster.
2. Every **Spoke** page links back to the Hub (via breadcrumbs and body content).
3. **Spokes** link to 2-3 highly related Siblings (e.g., `history-class` links to `language-learning`).
4. **Blog** posts link to the core Tool (`/editor`) using commercial anchor text ("Create a comic strip").

By isolating linking within the cluster, we create a dense semantic web that signals deep expertise in "Educational Comics" to search engines.
