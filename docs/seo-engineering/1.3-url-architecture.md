# URL & Internal Link Architecture

To achieve topical dominance, the Comic Strip Creator leverages a flat, subfolder-based URL architecture coupled with dense internal linking. This prevents orphaned pages and maximizes the flow of PageRank.

## 1. URL Architecture Examples

**Rule:** Maximum 3 levels deep (`/category/item`). Avoid subdomains to consolidate domain authority.

### Cluster: Templates (`/templates`)
- `/templates/education`
- `/templates/marketing`
- `/templates/social-media`

### Cluster: Use Cases (`/use-cases`)
- `/use-cases/teachers`
- `/use-cases/students`
- `/use-cases/product-managers`

### Cluster: Comparisons (`/vs`)
- `/vs/comic-strip-vs-storyboard`
- `/vs/comic-strip-vs-manga`

## 2. Rationale: Subfolders vs. Subdomains

We strictly use **subfolders** (`example.com/templates`) rather than subdomains (`templates.example.com`).
- **Link Equity:** Google treats subdomains as separate entities for ranking purposes. Backlinks to a subdomain do not reliably pass full authority back to the root domain. Subfolders consolidate all link equity into a single domain entity.
- **Crawl Efficiency:** Crawlers allocate crawl budgets per hostname. Subfolders ensure the primary domain's crawl budget is utilized efficiently across all clusters.

## 4. Internal Linking Logic (TypeScript)

This logic automates the creation of a "Related Tools" or "Related Pages" section, ensuring every spoke page links back to the hub and to 2-3 sibling pages.

```typescript
// src/lib/seo.ts
export type PageNode = {
  slug: string;
  title: string;
  cluster: "use-cases" | "templates" | "vs" | "blog";
};

/**
 * Generates an automated internal linking graph for a specific page.
 * Returns:
 * 1. The Hub page for the cluster.
 * 2. 3 random sibling pages from the same cluster (excluding the current page).
 */
export function generateInternalLinks(
  currentPageSlug: string,
  currentCluster: PageNode["cluster"],
  allPages: PageNode[]
) {
  // 1. Link back to Hub
  const hubLink = {
    slug: `/${currentCluster}`,
    title: `All ${currentCluster.replace("-", " ")}`,
  };

  // 2. Link to siblings
  const siblings = allPages.filter(
    (page) => page.cluster === currentCluster && page.slug !== currentPageSlug
  );

  // Shuffle and pick top 3 (use a seeded random for SSR consistency if needed,
  // or a deterministic relation like 'next 3 in array')
  const relatedSiblings = siblings.slice(0, 3).map(page => ({
    slug: `/${page.cluster}/${page.slug}`,
    title: page.title,
  }));

  return {
    hub: hubLink,
    related: relatedSiblings,
  };
}
```
