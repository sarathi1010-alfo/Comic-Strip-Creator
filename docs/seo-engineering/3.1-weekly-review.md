# Weekly SEO Review Framework

This SOP defines the weekly process for analyzing Google Search Console (GSC) and Google Analytics 4 (GA4) data to drive the programmatic SEO roadmap.

## 1. Breakout Tools Analysis
**Question:** Which programmatic pages are gaining traction?
- **GSC Filter:** Compare Last 7 Days vs. Previous 7 Days. Sort by Clicks (High to Low).
- **Action:** If a page shows a >20% increase in clicks:
  - Add deeper content to the page.
  - Link to it from the homepage or higher-level hub.
  - Review Search Queries for that page to extract exact-match keywords for H2s.

## 2. Opportunity Queue (Low CTR)
**Question:** Which pages have high visibility but poor engagement?
- **GSC Filter:** Last 28 Days. Impressions > 1,000. CTR < 2%.
- **Action:**
  - Rewrite the Title Tag (`<title>`) to be more compelling (e.g., add "Free", "Online", or current year).
  - Rewrite the Meta Description.
  - Add Schema markup (e.g., `FAQPage`) to capture rich snippets.

## 3. Latent Rankers
**Question:** Which queries are we ranking for on page 2 or 3 that could easily hit page 1?
- **GSC Filter:** Last 28 Days. Average Position between 11 and 30. Sort by Impressions.
- **Action:**
  - Increase internal links to the target page using the exact latent query as anchor text.
  - Update the page content to specifically mention the query.

## 4. Intent Mismatch
**Question:** Which pages get impressions but zero clicks?
- **GSC Filter:** Last 28 Days. Impressions > 500. Clicks = 0.
- **Action:**
  - Search the query manually. Are we offering a text guide when the user wants an interactive tool?
  - Consider consolidating this page or redesigning its UI to match search intent.

## 5. New Tool Expansion
**Question:** What new programmatic pages should we generate?
- **GSC Filter:** Search queries containing "comic", "strip", "generator", "creator". Sort by impressions. Look for queries where we have NO dedicated page.
- **Action:**
  - Add the new topics to the corresponding JSON data source (e.g., `seo-use-cases.json`).
