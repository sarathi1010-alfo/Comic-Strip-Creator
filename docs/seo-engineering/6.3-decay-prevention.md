# Content Decay Prevention System

Programmatic pages left untouched for 12 months will slowly lose rankings to fresher competitor content.

## Detection Workflow (Monthly)
1. Open GSC -> Compare Last 28 Days vs. Previous 28 Days.
2. Filter for pages with > 100 impressions last month.
3. Sort by Impressions Difference (Ascending).

## Severity & Action
| Severity | Definition | Action |
| :--- | :--- | :--- |
| **Mild Decay** | 10-20% impression drop | **Refresh Metadata:** Update title tag (e.g., add current year). Ensure canonical is intact. |
| **Moderate Decay** | 20-50% impression drop | **Content Injection:** Add a new H2 or FAQ block to the programmatic template. Update internal links. |
| **Severe Decay** | > 50% impression drop | **Full Audit:** Check if search intent shifted. Rewrite the JSON data for this slug entirely. |

## Quarterly Freshness Update Checklist
- [ ] Update any references to the "Current Year" in title tags and text.
- [ ] Ensure any referenced "competitor" features in `/vs/` pages are still accurate.
- [ ] Check for broken external links in `/blog/` content.
- [ ] Run the "Keyword Expansion Loop" (SOP 3.4) specifically for decaying pages to find new sub-topics to add.
