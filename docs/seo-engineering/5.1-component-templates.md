# Component-Driven Tool Template System

To scale programmatic SEO rapidly, we rely on modular React components rather than hand-coding every page.

## Core Archetype: "The Informational Hub"

Used for Use Cases, VS, and Template categories.

### Props Interface

```typescript
interface HubPageProps {
  title: string;          // H1
  description: string;    // Subtitle / Intro paragraph
  features: {             // Array of benefits/features
    icon: React.ReactNode;
    title: string;
    description: string;
  }[];
  ctaText: string;        // Button text (e.g., "Start Creating")
  faq: {                  // For FAQPage Schema
    question: string;
    answer: string;
  }[];
  relatedLinks: {         // Automated internal linking graph
    slug: string;
    title: string;
  }[];
}
```

### Layout Flow
1. **HeroSection:** `title`, `description`, primary `CTA` linking to `/editor`.
2. **FeatureGrid:** 3-column layout mapping over the `features` array.
3. **HowItWorks / Methodology:** Static component explaining the client-side nature of the tool.
4. **FAQSection:** Accordion mapping over `faq` array.
5. **RelatedPages:** Grid of internal links mapping over `relatedLinks` array.

By standardizing this, launching a new Use Case simply requires adding a new JSON object to `src/data/seo-use-cases.json`.
