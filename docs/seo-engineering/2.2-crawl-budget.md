# Crawl Budget Optimization Plan

When scaling the Comic Strip Creator to 1,000+ programmatic pages, Googlebot's crawl budget becomes a constraint. This plan ensures efficient crawling.

## Principles for Next.js / Vercel
- **Flat folder structure** reduces crawl depth waste.
- **robots.txt** blocks non-public paths (APIs, admin, user-specific data).
- **Internal links** from high-authority hub pages increase crawl frequency for spoke pages.
- **Fast server response time** = more URLs fetched per Googlebot session.
- **Sitemap index** acts as a priority map for crawlers.

## Top 10 Optimizations

1. **Pre-render Everything Possible:** Use SSG for `/blog`, `/vs`, and `/templates`. Static files are served via Vercel Edge Cache instantly, maximizing crawl speed.
2. **Optimize ISR Revalidation Time:** Do not use `revalidate = 1`. Use `revalidate = 86400` (24h) or higher for programmatic pages. Crawlers shouldn't trigger expensive SSR rebuilds.
3. **Block Internal API Routes:** Add `/api/*` to `robots.txt` `Disallow`. Crawlers don't need to index raw JSON.
4. **Remove URL Parameters:** Avoid linking to internal pages using tracking params (`?ref=internal`). This creates infinite crawl traps.
5. **Implement Segmented Sitemaps:** Once hitting > 1,000 URLs, split `sitemap.ts` into an index file pointing to `sitemap-use-cases.xml`, `sitemap-blog.xml`, etc.
6. **Limit DOM Size:** Next.js can output massive HTML files if hydration state is huge. Keep JSON payload sizes small to speed up Googlebot parsing.
7. **Optimize Next/Image:** Ensure all programmatic images use `next/image` to prevent crawling massive uncompressed PNGs.
8. **Fix Redirect Chains:** Ensure no internal link goes to a URL that 301s to another URL. 1 click = 1 page.
9. **Eliminate 404s:** Prune broken internal links. A 404 wastes a crawl request.
10. **Use Edge Runtime (where applicable):** For simple SSR pages, configure `export const runtime = 'edge'` to reduce cold starts.

## robots.txt Template

```text
User-agent: *
Allow: /

# Block API routes
Disallow: /api/

# Block auth routes (if added later)
Disallow: /login
Disallow: /signup
Disallow: /dashboard

# Block staging/preview branches (handled dynamically in Next.js)
# See src/app/robots.ts

Sitemap: https://comic.alfo.online/sitemap.xml
```

## Monitoring Plan (GSC)
- **Weekly Check:** Coverage -> "Crawled - currently not indexed". (If high, crawl budget is fine, but content quality is low).
- **Weekly Check:** Coverage -> "Discovered - currently not indexed". (If high, crawl budget is exhausted. Site is too slow or architecture is too deep).
- **Weekly Check:** Settings -> Crawl Stats. Monitor average response time and total crawl requests.
