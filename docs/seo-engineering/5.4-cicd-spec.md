# Deployment Pipeline & CI/CD Spec

The CI/CD pipeline ensures that scaling the number of pages never degrades technical SEO quality.

## GitHub Actions Workflow (`.github/workflows/seo-ci.yml`)

1. **Linting & Type Checking:** Prevents broken code from deploying.
2. **Build Test:** Ensures Next.js can successfully build all static and SSR routes.
3. **Automated Submission:** (Future State) Once deployed to production, triggers the `scripts/submit-sitemap.js` to ping Google Search Console.

## Vercel Integration
- **Preview Deployments:** Handled automatically by Vercel. `src/app/robots.ts` blocks crawlers from indexing `*.vercel.app` URLs.
- **Production Deployments:** When merged to `main`, Vercel deploys to the production URL, and `robots.txt` automatically opens the site to crawlers.
