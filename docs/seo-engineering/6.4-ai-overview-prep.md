# AI Overview & Answer Engine Optimization Prep

As Search Generative Experience (SGE), Perplexity, and ChatGPT become primary search interfaces, programmatic pages must be designed for *chunk extraction*.

## Principles for Citation Likelihood
AI models cite sources that are:
1. **Concise & Factual:** Short sentences, clear definitions.
2. **Highly Structured:** Heavy use of H2s, H3s, Bullet points, and Tables.
3. **Machine-Readable:** Perfect schema markup.

## FAQ Engineering
Every programmatic page (e.g., Use Cases) must have a FAQ section.
- **Format:** Question as H2/H3. Answer immediately below in a single, self-contained paragraph (40-60 words max).
- **Structure:** Start the answer by directly confirming the question. (e.g., Q: "Is the comic creator free?" A: "Yes, the comic creator is 100% free with no watermarks.")

## Example: Schema Implementation (Next.js)

```typescript
// Add to page.tsx metadata or inject in the body
export function generateFAQSchema(faqs: { question: string, answer: string }[]) {
  return {
    "@context": "https://schema.org",
    "@type": "FAQPage",
    "mainEntity": faqs.map(faq => ({
      "@type": "Question",
      "name": faq.question,
      "acceptedAnswer": {
        "@type": "Answer",
        "text": faq.answer
      }
    }))
  };
}
```

## Structural Changes for AI Retrieval
1. **Answer-First Introductions:** The first 50 words of the page must define exactly what the page is about.
2. **Definitional Chunks:** Use `<strong>` tags for core concepts.
3. **Avoid Fluff:** AI models discard conversational filler ("In today's fast-paced world..."). Cut straight to the utility.
