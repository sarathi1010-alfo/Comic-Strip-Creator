# AI-Assisted Page Generator Prompt

When you need to expand the JSON data sources for programmatic pages, use this prompt with an LLM.

---

**Prompt:**

```text
I am expanding my programmatic SEO site. I need a new JSON object to add to my `seo-use-cases.json` array.

Target Topic: Comic Strips for Real Estate Agents
URL Slug: `real-estate`

Generate the JSON object following this exact interface:

```typescript
{
  slug: string;
  h1: string;
  metaTitle: string; // Max 60 chars
  metaDescription: string; // Max 155 chars
  description: string; // 2-3 sentences explaining the value
  features: [
    { title: string, description: string } // Exactly 3 features
  ],
  faq: [
    { question: string, answer: string } // Exactly 3 FAQs, optimize answers for AI Overview extraction (concise, factual)
  ]
}
```

Make the tone professional yet creative. Focus on how visual storytelling helps sell homes.
```
