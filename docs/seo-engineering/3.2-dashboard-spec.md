# GSC + GA4 Integration Dashboard Spec

A custom dashboard (e.g., Looker Studio or custom internal tool) to monitor the health of the programmatic ecosystem.

## Data Sources
- **GSC:** URL, Query, Impressions, Clicks, CTR, Position.
- **GA4:** Page Path, Sessions, Engagement Time, Custom Events.

## Dashboard Sections

### 1. The "Breakout" Monitor
- **Visualization:** Bar chart.
- **Data:** Top 10 pages by MoM (Month-over-Month) percentage increase in organic sessions.
- **Purpose:** Identifies algorithms rewarding our content.

### 2. The "Fix Me" Queue (CTR Optimization)
- **Visualization:** Table.
- **Data:** Pages with >1k impressions, Position 1-5, but CTR < 5%.
- **Fields:** Page URL, Top Query, Impressions, Position, CTR.
- **Purpose:** Low-hanging fruit for title/meta optimization.

### 3. Engagement Health
- **Visualization:** Scatter plot (Sessions vs. Avg Engagement Time).
- **Data:** Filtered to `/use-cases/` and `/templates/` routes.
- **Purpose:** Identifies pages that get traffic but don't satisfy intent (high sessions, low time).

### 4. Custom Tool Events
- **Visualization:** Scorecard + Trendline.
- **GA4 Events:** `export_comic`, `add_panel`, `change_character`.
- **Purpose:** Maps organic traffic directly to core product utility. Are SEO visitors actually using the tool?

### 5. Content Decay Alert
- **Visualization:** Table.
- **Data:** Pages with >30% drop in MoM impressions.
- **Purpose:** Flags pages that require a content refresh or date update.
